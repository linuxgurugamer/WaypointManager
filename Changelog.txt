Changelog

2.8.5 
	From github user @clayell:
		Added support for Kopernicus City2 waypoints
	Added code to show the Kopernicus buttons only when available
	Added new right-click to the toolbar button to show/hide all waypoints
	Added new button to settings to disable/enable the right-click menu on the toolbar button
	Updated code to show correct version number in title bar
	Fixed issue with selecting icons for custom waypoints, now shows the correct icon in the selection window, was getting an exception and not showing the selection window
	Fixed issue with grouped waypoints on other planets not being shown
	Removed toolbar icon from MainMenu, which was also putting it on the Space Center toolbar
	Added default marker in case a bad icon path is loaded
	Fixed issue with Kopernicus City2 markers having the wrong name for the marker
	Removed old code loading dds or png, replaced with ToolbarControl.LoadImageFromFile()
	Added code to only use marker icons for picking a marker for a waypoint (also will include the toolbar-blue)
	Added a white marker so color change will work properly
	Added code to not apply color changes to colored markers
	For development, added code to support the HotReload mod
	Fixed issue where opening the Add/Del Waypoint window in the Tracking Station and then going back to the Space Center without closing the windows would see the windows remain open
	Converted all GUILayout.BeginHorizontal/GUILayout.EndHorizontal and GUILayout.BeginVertical/GUIlayout.EndVertical to using the newer HorizontalScope/VerticalScope
	Added code to prevent invalid numbers from causing errors when entering a manual waypoint
	Added code to delete CITY2 waypoints when leaving Flight or Tracking Station, and add them back when returning
